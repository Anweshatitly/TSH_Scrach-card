The Stationery Hub — Scratch Card System
==========================================

WHAT'S IN THIS ZIP
-------------------
counter.html   Staff page — enter customer + bill, saves the record, gives you a link to send
card.html      Customer page — what you send them, they scratch to reveal the gift
logo.png       Your original logo (already embedded inside both HTML files too)
README.txt     This file

HOW THE TWO PAGES WORK TOGETHER
---------------------------------
counter.html is the ONLY page with a database (records, today's sales, "given" checkboxes,
CSV export). That database only works when counter.html is opened through its claude.ai
artifact link:

  https://claude.ai/artifact/Qe7u2ZGghTE2qyvVjqCqhe

Do NOT rely on a self-hosted copy of counter.html for record-keeping — records and saving
will not work outside the claude.ai link. Keep using that link day-to-day at the counter.

card.html has NO database. It's safe to host anywhere — GitHub Pages, Netlify, your own
server. Each customer's name, phone, bill and gift are carried inside the link itself
(after the # symbol), not stored on the page. The customer can see their details but
cannot edit them, and can only reveal the gift by scratching.

YOUR CURRENT SETUP
--------------------
card.html is hosted at:
  https://anweshatitly.github.io/TSH_Scrach-card

counter.html's CARD_URL variable (near the top of its <script> tag) is already set to
that address, so links generated by the counter page point to the right place.

IF YOU EVER MOVE card.html TO A NEW ADDRESS
----------------------------------------------
1. Open counter.html in a text/code editor.
2. Find this line near the top of the <script> section:
     const CARD_URL = "https://anweshatitly.github.io/TSH_Scrach-card";
3. Replace the address with your new one (no trailing slash).
4. Save, then re-publish/re-upload counter.html wherever you use it from.

TESTING THE FULL FLOW
------------------------
1. Open the counter page (claude.ai link above).
2. Enter a test name, phone, and a bill amount like 500.
3. Tap "Make card & get link" — this saves the record and shows you the gift + a link.
4. Open that link (or send it to yourself on WhatsApp) — it should show the customer's
   name, phone, bill, and a gold scratch panel.
5. Scratch it — the gift should be revealed underneath.
6. Back in the counter page's Records tab, tick "given" once you hand over the gift.
